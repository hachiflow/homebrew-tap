# Decision log

This is the homebrew-tap repo's log of decisions whose reason a reader could not see
in the files themselves. Each row is one decision. Only a person adds a row:
at the bottom, with the next id, today's date, a title of one sentence (80
characters at most, no `|`), one sentence of why, the earlier id it
supersedes if any, the test file or check that fails when the decision is
broken (in backticks) and the person who decided. Rows are never edited or
removed; a reversal is a new row that names the old id under Supersedes.

This repo holds one formula that GoReleaser generates and rewrites on every release. Nothing checks this file here. If hand-written source ever lands in
this repo, it takes the same `check-comments` check the other hachiflow
repos run, before the first source file merges.
